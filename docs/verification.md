# 运行环境与结果

基础程序采用ECFP4分子指纹和逻辑回归，对真实分子样本完成预测，并计算AP与AUROC。实验环境为Windows、Python3.12.3、RDKit2024.03.2、NumPy1.26.4、SciPy1.15.2和scikit-learn1.6.1。

| 项目 | 实际记录 |
|---|---|
| 训练数据 | 2,000条，阳性30条 |
| 验证数据 | 1,000条，阳性15条 |
| AP | 0.0379490864 |
| AUROC | 0.6278849408 |
| 数据检查 | 记录、分子和scaffold跨侧检查通过 |
| 基础Notebook | 3个代码单元实际执行完成，结果与命令行一致 |
| 分阶段Notebook | 01—04分别执行2、2、3、2个代码单元，均完成 |
| 模型比较案例 | 读取26体系历史M0/M1记录 |
| 搜索案例回放 | 读取30条提案、20个评价候选与520条体系记录，重算评价轨迹一致 |
| 任务配置示例 | 完成策略字段解析及本地任务准备 |

Notebook通过项目本地Jupyter内核运行。基础实验输出在 `outputs/baseline/`；分阶段运行记录在 `outputs/learning-notebook-verification.json`，各Notebook保留实际执行后的文件。数据来源和样本抽取记录见 `data/internal/source_manifest.json`。

基础样本实验用于预测与评价教学；M0/M1和L6案例采用对应研究资料。各项结果按其任务和来源解释。
