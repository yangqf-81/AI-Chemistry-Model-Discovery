# 学生项目任务书

你所在的小组选择GNN＋N2V与伐谋方向，在一个学期的32学时实践中完成一个真实化学课题。同班其他小组可以承担不同课题。本组围绕具体问题设计必要对照，形成自己的研究方案。

## 任务与自主空间

1. 自主明确具体化学问题、标签含义与可做范围；教师提供资源和边界。
2. 解释分子图/GNN与化学空间图/N2V的不同作用，比较M0/M1并提出优化假设。
3. 自行设计搜索空间、目标、评价规则、预算与停止条件；教师给模板，不替你决定最佳策略。
4. 参与AI提案—程序执行—开发评价反馈，保留失败和修订理由；平台不可用时按教师指定真实日志分析并注明模式。
5. 选定方案后评价保留结果，形成有限结论与下一步检验，不把保留结果回流本轮调参。

## 五次阶段提交

| 检查点 | 提交物 | 教师反馈后你的工作 |
|---|---|---|
| C1，第2次活动 | 问题说明、数据边界、两类表示图 | 回应问题范围和数据解释意见 |
| C2，第5次活动 | M0/M1比较、解释及问题修订 | 指出哪些判断改变，依据是什么 |
| C3，第8次活动 | 搜索问题卡v1 | 回应可执行性、预算和评价设计意见 |
| C4，第13次活动 | 候选/失败记录、修订、方案选择与冻结 | 说明探索和权衡，保存选择前证据 |
| C5，第16次活动 | 学期档案、保留评价、报告、个人答辩 | 总结能力变化与未来问题 |

每次活动和重要计算更新学期研究档案，保存“原判断—新证据—新判断”。可改变开发假设并再次尝试，但必须留版本与理由；不得为追求高分扩大计算预算或重选保留评价最好的模型。

## 交付与评价

提交问题说明、模型比较、搜索问题卡、候选记录、学期过程档案和报告。记录哪些结果自己运行、哪些来自教师、哪些是历史研究。评价既看成果，也看问题、决策和证据怎样发展；没有提升并不自动扣分。
