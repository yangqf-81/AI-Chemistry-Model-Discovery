# 校企合作内容

本项目将化学课题、模型开发与自动优化结合起来。四川大学课程团队负责真实化学问题、教学任务、阶段反馈和学习评价；百度伐谋团队提供平台技术支持。

| 工作环节 | 四川大学课程团队 | 百度伐谋技术支持的作用 |
|---|---|---|
| 化学问题与建模 | 组织课题选择、数据理解、M0/M1比较 | 支持理解自动优化工具的适用方式 |
| 搜索任务设计 | 引导学生定义空间、目标、预算和评价 | 支持候选策略表达与平台任务对接 |
| 人机协同实践 | 组织执行、反馈讨论和方案选择 | 提供伐谋相关技术支持 |
| 科学评价 | 组织对照、保留评价、研究档案与答辩 | 作为自动优化实践工具支撑教学活动 |

合作的教学价值在于让学生参与模型开发任务的定义与评价：教师提供化学与教学支持，AI工具提供候选探索，学生依据证据作出研究判断。
