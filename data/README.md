# 教学数据说明

基础程序读取训练与验证CSV，每行一个分子记录，必需字段为：

| 字段 | 含义 |
|---|---|
| canonical_smiles | 可由RDKit解析的分子结构 |
| label | 当前课题的二分类标签，0或1 |
| record_id | 数据记录身份 |
| generic_scaffold_id | 预先确定的scaffold分组 |

训练与验证必须按原划分分别提供；程序拒绝分子、记录或scaffold跨两侧重复。不得为了提高结果事后调整划分或删除失败样本。

`internal/` 为本机技术验收样本，默认被Git忽略。其来源为已盘点的AID_560 Search26数据，保持原训练/验证边界，预先固定随机抽样规则，记录在本地来源清单。它仅用于基础程序验收，不等于已选定最终教学课题，也不等于已获公开再分发许可。

公开前补齐具体assay的化学背景、标签定义、源站及许可/引用要求。未完成前，本仓库不声称外部用户可下载全部数据运行。
