# 百度伐谋进阶实践

学生先定义优化问题，伐谋提出候选策略，执行程序训练并计算评价，反馈用于后续策略探索。人负责数据边界、目标、约束和最终科学判断。

L6是主要研究来源。历史流程使用受限声明式策略、可信编译器和独立执行器；教学不要求开放全部科研搜索轴或复做31体系。

当前阶段提供教学角色和历史材料定位；尚未宣称当前账号下的实时教学接口已验收。后续接口、配置示例与SDK依赖单独核对，凭据通过环境变量或平台凭据管理提供，不写入仓库。

无平台账号者仍可运行README中的基础预测与评价实验，再分析教师提供的真实搜索日志。报告中分别注明“实时搜索”或“历史案例分析”。两种模式不混记。

不将历史搜索收益解释为伐谋优于随机搜索或贝叶斯优化：现有证据未提供同预算搜索器对照。
